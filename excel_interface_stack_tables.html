📋 Excel Import Instructions

  1. Select Table: Click and drag to select any table below
  2. Copy: Ctrl+C (or use the Copy button)
  3. Paste in Excel: Ctrl+V in your Excel worksheet
  4. Apply Colors: Use the color guide below to format cells in Excel
  5. Auto-fit Columns: Select all columns and double-click column border to auto-fit
Logical Interfaces: RGB(255,107,107) - Service abstraction layer
IP Interfaces: RGB(78,205,196) - Layer 3 routing/addressing
Bridge Ports: RGB(69,183,209) - Layer 2 switching
Ethernet Links: RGB(150,206,180) - Protocol abstraction
Ethernet Interfaces: RGB(255,234,167) - Physical ethernet
WiFi SSIDs: RGB(221,160,221) - Wireless access points
WiFi Radios: RGB(255,182,193) - Physical radio hardware
PPP Interface: RGB(240,230,140) - WAN authentication
💡 Tip: After pasting in Excel, you can use Format Painter to quickly apply colors, or use conditional formatting based on the "Interface Type" column.

🎨 Excel Formatting Instructions

  1. Cell Color: Select cells → Home → Fill Color → More Colors → Custom → Enter RGB values
  2. Conditional Formatting: Select "Interface Type" column → Home → Conditional Formatting → New Rule → Format cells that contain → Apply colors based on text
  3. Auto-size: Select all columns → Home → Format → AutoFit Column Width
  4. Freeze Headers: Select row 2 → View → Freeze Panes → Freeze Top Row
  5. Borders: Select table → Home → Borders → All Borders
