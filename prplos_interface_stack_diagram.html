📊 Configuration Summary

  • Network Services: 7 logical interfaces (WAN, LAN, Guest, LCM, VoIP, Management, IPTV)
  • Physical Connectivity: 4 Ethernet ports + 3 WiFi radios (2.4GHz, 5GHz, 6GHz)
  • WiFi Coverage: 12 SSIDs across tri-band setup with enterprise profiles
  • Service Isolation: Separate bridges for LAN, Guest, and LCM networks
  • Advanced Features: DS-Lite tunneling, PPPoE support, Container LCM
